# Souk Junub Billing

BUILD A COMPLETE, PRODUCTION-GRADE ISP AND WIFI BILLING MANAGEMENT SYSTEM 

modeled after SopraEnt (sopraent.com), specifically adapted for the South Sudan 

market with South Sudanese Pound (SSP) as the sole base currency.

Brand: SOUK JUNUB

Base Currency: SSP (South Sudanese Pound) — ALL prices, transactions, reports, 

and analytics must display and calculate in SSP. No USD/UGX/KES fallback unless 

explicitly configured by admin for multi-currency display.

Target Market: South Sudan (Juba, Wau, Malakal, Bor, Rumbek, and rural VSAT/fiber)

Primary Telcos: MTN South Sudan (+211 92x), Zain South Sudan (+211 99x), Digitel (+211 98x) 

Language: English (primary), with i18n architecture ready for Arabic and local languages
